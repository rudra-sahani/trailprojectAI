# Accessibility Audit & WCAG 2.1 AA Checklist

## Verified Criteria
- [x] All interactive controls and form inputs have clear `<label>` or `aria-label` attributes.
- [x] Color contrast ratios pass WCAG AA (minimum 4.5:1 for body text).
- [x] Severity indicators (low, medium, high, critical) include both text/icons and color coding.
- [x] Full keyboard navigation supported across forms, review controls, and modals.
